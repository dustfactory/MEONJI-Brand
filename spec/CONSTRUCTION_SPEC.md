이 문서가 심볼의 **공식 수치 규격**이다. 원본 측정값과 분석은 [CONSTRUCTION_GUIDE.md](CONSTRUCTION_GUIDE.md) 참고.
규격대로 다시 그린 심볼: [redraw/meonji-symbol-spec.svg](redraw/meonji-symbol-spec.svg) (생성: [build_symbol.py](redraw/build_symbol.py), 검증: [verify_geom.py](redraw/verify_geom.py) → [VERIFY_GEOMETRY.md](redraw/VERIFY_GEOMETRY.md))

## 기준 단위
- **1u = 줄기(stem) 폭 = 51.31 격자 단위**
- 격자 → 원본 viewBox(`0 0 1254 1254`, 원본 1u = 173.7) 변환: `scale(173.7/51.31)`

## 참고 / 한계
- **비율**: 잉크 영역 가로:세로 ≈ **1.359** (정확한 4:3 = 1.333 아님). 귀 높이 0.6u를 우선했기 때문이며, 정확히 4:3을 맞추려면 귀 높이 ≈ 0.666u가 필요하다.
- **규격이 아닌 측정 근사값**: 몸통 바깥 곡선, 턱 아치, 수염 시작점 위치, 노치의 x 위치는 원본 측정값을 따라 근사한 것이다.
- 원본 심볼 파일(`svg/`, `master/` 등)은 변경하지 않았다. 원본과 비교: [overlay-spec-vs-original.png](redraw/overlay-spec-vs-original.png)
