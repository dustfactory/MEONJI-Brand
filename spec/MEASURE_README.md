# 먼지 로고 측정 도구 (meonji-measure.html)

파일 하나짜리 오프라인 도구야. 더블클릭하면 브라우저에서 열려(인터넷 필요 없음). 심볼·워드마크 원본 SVG와 ears.json 측정값이 파일 안에 들어 있어.

## 화면
- 상단: 심볼/워드마크 탭, **파일 열기…**(또는 화면에 SVG/PNG 끌어다 놓기), 도구 버튼
- 오른쪽: 보정(1u·원점·귀 기준선), 오버레이, 도구 옵션, **규격 검사**, 측정 목록
- 하단: 커서 좌표 (SVG 단위 / u, 원점=잉크 좌하단, 위쪽이 +)

## 단축키
| 키 | 기능 |
|---|---|
| R | 자 켜기/끄기 |
| P | 각도기 켜기/끄기 |
| M | 두 점 거리 측정 |
| A | 3점 각도 측정 (점1 → 꼭짓점 → 점2) |
| G | 1u 격자(¼u 보조선) |
| F | 화면 맞춤 |
| Esc | 진행 중인 측정 취소 / 모드 끄기 |
| Space+드래그, 빈 곳 드래그 | 화면 이동 |
| 휠, 트랙패드 핀치 | 확대/축소 |
| Shift(드래그 중) | 15° 단위 / 자 길이 ¼u 단위 고정 |

## 자
몸통을 드래그하면 이동, 끝의 ● 를 드래그하면 회전, ▶ 를 드래그하면 길이가 바뀌어. 눈금은 u(¼u 보조), "자에 단위 눈금"을 켜면 SVG 단위 눈금도 나와. **줄기에 놓기**를 누르면 왼쪽 줄기 왼쪽 끝(0u)에 맞춰 놓여서 1u 눈금이 줄기 오른쪽 끝과 맞는지 바로 볼 수 있어.

## 각도기
- **각도기 → 왼쪽/오른쪽 귀 밑동**: 중심을 바깥 귀 밑동(귀 기준선 위)에 놓고 0°선을 수평 기준선에 맞춰.
- 중심 ✚ 드래그 = 이동(윤곽점 스냅), 0° 옆 ● = 0°선 회전(또는 "각도기 0° 회전" 입력), 왼쪽 끝 ○ = 크기.
- 빨간 바늘 끝 ● 를 귀 옆선에 맞추면 각도가 0.1° 단위로 표시돼.

## 측정 (M / A)
클릭할 때 "윤곽점 스냅"이 켜져 있으면 가장 가까운 경로 노드/윤곽점으로 붙어(초록 원 = 스냅됨). 확대경(루페)이 커서 옆에 떠. 결과는 오른쪽 목록에 쌓이고 ✕로 지우거나 **CSV 내보내기**로 저장할 수 있어. **마지막 거리를 1u로**를 누르면 마지막 거리 측정을 기준 단위로 보정해.

## 오버레이와 규격 검사
- 귀 기준선(보라 점선), 측정된 귀 선(청록, ears.json), **제안 표준 귀 선**(빨강 점선: 바깥 67.5°, 안쪽 55°, 꼭짓각 57.5°, 밑동 1.0625u, 귀끝 R 0.1875u, 귀끝 높이 노치+0.625u), 여백 0.5u와 4.5×3.375u 박스.
- 표준 귀는 측정된 노치와 귀 기준선을 기준으로 작도해. 그래서 원본 윤곽과 빨간 선이 벌어진 만큼이 편차야.
- 규격 검사 표: 측정값 vs 표준, 차이, 통과/불합격. 허용 오차 기본 ±1°, ±0.02u이고 바꿀 수 있어.
- 로고/오버레이 불투명도 슬라이더로 겹쳐 보기.

## 한계
- 규격 검사 표의 측정값은 CONSTRUCTION_GUIDE.md / ears.json 값(자동 트레이스라 1–2° 오차 가능). 직접 잰 값은 측정 목록에 따로 나와.
- 불러온 파일은 귀 데이터가 없어 규격 검사·귀 오버레이가 꺼지고, 1u는 잉크 폭/4.5로 임시 설정돼(보정 칸에서 수정).
